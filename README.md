# DevOps-Lab05.2

## เกม Jigsaw Puzzle

เปิดไฟล์ `index.html` ด้วย Browser บนเครื่อง PC เพื่อเล่นเกมต่อภาพรถ 20 ชิ้น โดยลากชิ้นส่วนจากพื้นที่ด้านข้างไปยังตำแหน่งบนกระดาน เมื่อวางใกล้ตำแหน่งที่ถูกต้อง ชิ้นส่วนจะล็อกเข้าที่

กด **เริ่มเกมใหม่** เพื่อสุ่มตำแหน่งชิ้นส่วนอีกครั้ง เกมมีเสียงเอฟเฟกต์ตอนกดและวางชิ้นส่วน และเล่นเพลงประกอบจาก `game-music.mp3` ซึ่งปิดหรือเปิดได้จากปุ่มด้านบน เพลงจะเริ่มเล่นเมื่อ Browser อนุญาต (บาง Browser ต้องกดชิ้นส่วนหรือปุ่มเปิดเพลงก่อน) และจะเริ่มเล่นซ้ำเมื่อเพลงจบ

เกมใช้ HTML, CSS และ JavaScript โดยไม่ต้องติดตั้งไลบรารีเพิ่มเติม โหลดภาพจาก `car.jpg` และเพลงจาก `game-music.mp3` ในโฟลเดอร์เดียวกับ `index.html`
